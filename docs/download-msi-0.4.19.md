# Página de download do piloto MSI 0.4.19

Em 07/10/2026, a [prerelease manual 0.4.19](https://github.com/luisotvbim-sudo/CEP-FRONT/releases/tag/installer-v0.4.19) foi publicada com sete assets, `latest=false`, tag no commit `d4c7f8d` e CI `validate`/`desktop` aprovada na segunda execução do run 37675171616. O MSI tem SHA-256 `e905cecc7d8602ae17cdecb57f6ab6adb6b5a51ac71011ae2f313ac7ebb22de8`; o manifesto e a assinatura correspondem à identidade pública embutida. Os digests dos sete assets na API do GitHub conferiram com os arquivos locais; manifesto e assinatura foram baixados anonimamente com hashes iguais, e MSI/kit responderam HTTP 200 em HEAD anônimo. O MSI continua sem Authenticode.

O piloto 0.4.18→0.4.19 em uma estação Windows 11 Pro terminou com versão e serviço corretos, login e Histórico do período visível. Após revalidação pessoal de 20 dias, registros importados de hoje apareceram. Os cartões acima consultam fontes ao vivo; o resumo importado de um dia parcial pode permanecer indisponível mesmo com registros, preservando valores desconhecidos como nulos. Windows 10 não foi testado especificamente nesta versão, e energia, rollback e atualização automática permanecem fora deste piloto.

Esta branch da `main` web muda somente o card `/download` de 0.4.18 para 0.4.19, preserva a distribuição manual acompanhada, avisa que o piloto específico foi Windows 11 e mantém os avisos de Authenticode e canal automático fechado. O link do convite da API continua apontando à página genérica, sem versão; a API não muda. A publicação web depende de CI do commit exato, backup/rollback da imagem e conferência de ambos os domínios após implantação. A release do MSI, a integração do código web e a implantação são estados distintos.
